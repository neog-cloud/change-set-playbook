# Convenção de nomes

## IDs

Use `CS-001` a `CS-999`. Após alcançar `CS-999`, continue com `CS-A01` a `CS-A99`, depois `CS-B01` a `CS-B99` e assim sucessivamente.

## Caminhos recomendados no projeto-alvo

```text
docs/change-sets/
├── index.md
└── cs-001/
    ├── planning.md
    ├── specification.md
    └── review-cs-001.md
```

Nomes de diretório usam minúsculas. Nomes visíveis usam `Change Set CS-001`.
