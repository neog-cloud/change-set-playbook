# Documentação de funcionalidades

Esta pasta contém a fonte canônica do comportamento funcional atual do sistema.

Antes de criar um arquivo, procure um documento que já represente o mesmo domínio funcional e atualize-o. Crie um novo somente quando a funcionalidade ainda não estiver documentada, usando o [modelo de funcionalidade](../../templates/feature.md).

Regras:

- descreva o comportamento atual, não o plano de implementação;
- organize por domínio funcional, não por issue;
- use nomes em minúsculas, sem espaços e com `_` entre as palavras;
- remova informações que deixaram de ser verdadeiras;
- use links para contratos ou decisões existentes em vez de duplicá-los;
- registre mudanças relevantes na tabela “Evolução” com referência à issue ou ao PR.
